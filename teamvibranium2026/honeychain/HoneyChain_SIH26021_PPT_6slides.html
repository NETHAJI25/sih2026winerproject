How It Works — 5-Step Farm→Jar + Smart Hive

  1. Farmer: geo-photo + farmerWeight 42kg → Batch B-1042 → RTDB + Polygon BatchCreated
  2. Driver: geo-allocated, scale 41.8kg, GPS+seal photo → Custody Transfer (AI flags >2% gain)
  3. Lab: got 41.6kg → IS4941 6 params + seal photo + tester pic → QualityAttached certHash — only PASS → packer
  4. Packer: got 37.9kg → mints 500 jars QR hc.in/b/B-1042 → JarsMinted packer-only
  5. Consumer: scan QR → TrustBadge verified + farm story + lab report + HiveMonitor link — physics 42→55kg flagged
IoT Hardware: ESP32 + DHT22 (temp 32-37°C) + humidity 50-75% + HX711 weight + MAX9814 mic (sound 58-68dB) + battery → Firebase RTDB 12s → AI RF 120 trees 95.56% (12k + 47k Kaggle: US honey 1k + bee images 5k + varroa 20k) → HiveMonitor recharts + colony health + disease Varroa/Foulbrood 10 guide + yield ML+rule → /hive-health /disease-detect (Our RF / Gemini) /productivity
