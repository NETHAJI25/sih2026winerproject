# SIH26017 — Features & MVP Scope

## MVP (submission demo)
| # | Feature | Demo-visible? |
|---|---|---|
| 1 | District war-room map with risk-tiered parcels | Yes |
| 2 | Case 360° view: statutory clock timeline + documents + parties | Yes |
| 3 | ML risk score P(breach) per case + time-to-completion estimate | Yes |
| 4 | SHAP explainability panel in plain English | Yes |
| 5 | Auto-alerts (email/WhatsApp-mock) when case enters red tier | Yes |
| 6 | What-if intervention simulator | Yes |
| 7 | Synthetic dataset generator + methodology page | Shown briefly |

## V2 (finale depth)
- Survival-curve comparison across districts (benchmarking)
- Role-based views: Collector / DLR0 / State committee
- Farmer-facing public status tracker (transparency angle)
- Escalation workflow with SLA timers
- Model performance dashboard (precision/recall, calibration)

## V3 (roadmap slide only)
- ULPIN/Bhu-Naksha live integration
- Multilingual farmer notifications
- Integration hooks for state land-records APIs

## Non-goals
- No blockchain here (keep it lean — differentiator is prediction quality + UX)
- No scraping private data; all sources public/synthetic

## Demo seed data
~800 cases across 3 fictional-but-realistic districts; 60 red-tier; embed 3 narrative hero cases: (a) compensation-lag classic, (b) litigation pileup, (c) success story where early alert saved a school project.
